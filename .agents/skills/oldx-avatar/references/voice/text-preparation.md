# TTS 文本预处理与自然表达

在合成前读取。先形成两种模型共用的自然口播底稿，再按模型编译控制参数。不能只给 MiniMax 改口语、让 Qwen 靠指令补救书面句式。

## 保留三层材料

- `source.txt` 保留用户原稿；事实、数字、英文名称不擅自改动。
- `spoken-text.txt` 保存用户确认的口语化底稿，不包含控制标签。记录有意义的改写与发音修正。
- 各模型的请求文件分别保存正文、发音配置、语气指令和停顿／呼吸标签。审阅用的中文表演提示不直接发送，也不进入字幕。

字幕默认使用确认后的口播底稿，保留正确汉字与英文拼写，去掉控制标记；用户指定原稿字幕时遵从其选择。不要把谐音替代字或拼音显示在字幕里。

## 先处理给耳朵听的文字

通读整稿，按语意拆开难以一口气说完的长句，补足听觉上不清楚的主语，保留长短句变化。允许少量自然衔接，不机械添加语气词。

已获用户认可的改写方向：

| 原句 | 口播处理 |
|---|---|
| 停下来了，还需要催它下一步 | 它停下来了，还得催它下一步 |
| 怕它跑了十几个小时 | 就怕它跑了十几个小时 |
| 每个任务有自己的执行会话和工作目录 | 每个任务都有自己的执行会话，也有自己的工作目录 |
| 人检查过以后 | 等人检查过以后 |
| 需要做方向选择时再找人 | 碰到需要做方向选择的地方，再找人 |

这些是示例，不是全局替换词典。先理解语境，再决定是否修改。不能为了活人感每句都加“就、还、其实、嗯、啊”，也不虚构作者经历或增加事实。

检查多音字、数字单位、中英文混读。优先使用模型原生发音控制，只有实际读错且原生控制无效时，才对合成输入做局部同音替代，并记录原词；不要给所有多音字强制标音。

保留英文名称，例如 codex、deepseek、super agent、github，不转写成中文谐音。保留英文不等于已验证其发音，试听时仍要检查。

本次语境中“还得”读 hái děi，“重新”读 chóng xīn。“一样”的异常曾在强制标音后仍存在，不能把尾音失真一概当作多音字错误。

## 模型适配

默认 MiniMax 2.8 HD（`speech-2.8-hd`），用户明确指定其他模型时遵从。声音复刻、密钥与音频导入见 [tts-quality.md](tts-quality.md)。音色按提供商和模型匹配，不能跨引擎复用。

### MiniMax 2.8 HD

- 使用 `pronunciation_dict.tone`，例如 `还得/(hai2)(dei3)`、`重新/(chong2)(xin1)`。
- 语意转折处可用 `<#0.25#>`、`<#0.3#>` 等停顿；注意与标点已有的停顿叠加。
- 需要可闻气口时，少量使用 `(breath)`。本次约两分钟全文在引入研究原型前和“不过”前各放一处，用户选定该音频并确认视频；这不代表以后所有文案固定放两处。
- 首轮可不固定全篇 emotion，让语境引导表达；不要把 Qwen 的 instruction 或方括号情绪标签直接移植进来。
- 本次沿用降噪复刻音色，`speed=1`、`vol=0.7`、`pitch=0`、32kHz 单声道 WAV，无后期调速或滤波。参数是已确认案例，不是所有音色的通用最佳值。

### Qwen 3.1 TTS Plus（按需选择）

- 使用整体 `instruction` 说明人物、场景、语速变化、重点、句末收音和语气转折，避免只有“自然、有感情”这类空泛要求。
- 发音可用 `hot_fix.pronunciation` 或 SSML `phoneme`；SSML 输入需要 `enable_ssml=true`，停顿用 `break`。
- 自然轻换气可作为指令中的表达意图，不能保证每处都生成可闻呼吸。没有核对支持前，不发明 `[breath]` 等标签，也不把 gasp 或 sigh 当普通呼吸。
- 本次 Plus 使用同一口语底稿、整体指令和 SSML，整篇合成成功。不要据此强制每篇加 excited 或 curious；历史 Flash 的标签经验不能直接作为 Plus 的默认。

## 审阅、试听、交接

1. 原稿处理为统一口语底稿，列出重要改写、发音规则与表达设计，供用户审阅。用户已授权改稿并确认底稿时直接沿用，不重复索要相同确认。
2. 按用户要求合成短段或全文。新音色、曾有尾音问题时优先短段试听；用户明确要求全文或横向比较时按其范围执行。整稿不超过现有长度限制时尽量一次合成，不逐句拼接。
3. 保存请求参数、模型、音色、来源、请求号、实际时长、音频指纹和计量信息，不保存密钥。保留旧版本。
4. 检查可解码性、真实时长、峰值及满幅采样，再做 ASR 文字核对。接口 WAV 可能带流式占位长度头；本次 Qwen 文件头显示约六小时，实际 PCM 只有 130.41 秒。遇到这种情况保留原文件，只重封装 WAV 头，核对 PCM 样本未变后再建立指纹和对齐。
5. ASR 相似度和没有满幅采样点都不能证明没有爆音、电子尾音或机械感。让用户试听“一样”“烧心”等既往问题词、英文及气口；识别差异单列，不擅自重做整篇。
6. 用户认可音频后按外部音频交接契约进入视频阶段。自然气口是设计内容，后续不能把低能量呼吸统一当杂音删除。跳剪前检查切点是否覆盖气口或设计停顿；现有脚本没有逐处保护区接口时，保留原片并调整已有阈值／余量做预览，无法保留则先交付原片，不假装已支持自动保护。

本次 MiniMax 全文 134.35 秒，ASR 相似度约 0.995；“批个”被识别成 pick，需要试听区分识别错误与实际发音问题。用户最终选择 MiniMax 并于 2026-11-02 指定其为技能默认。Qwen Plus 仍为可选路线。
